# Extracción de datos 1

Este proyecto es una práctica introductoria de extracción de datos. Su idea principal es obtener información desde una fuente de datos y prepararla para su posterior análisis.

La práctica sirve para explorar el proceso básico de recopilar datos y entender cómo convertirlos en información útil. Los detalles de las fuentes y herramientas utilizadas se documentarán aquí a medida que avance el proyecto.
